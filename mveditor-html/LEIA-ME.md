# Cliente MV Editor HTML — Supreme Version

Interface HTML e melhorias por Rodrigo Amorim Dillemburg, com assistência de IA.

Este cliente depende dos serviços de uma instalação autorizada do MV Editor. Leia os guias em WEB-INF/documentacao e as condições em LICENCA.txt e TERCEIROS.md.

Atualização: preserve a configuração particular do servidor, copie os arquivos mantendo as subpastas e use Ctrl+F5. O config.js distribuído é genérico; não contém parâmetros de atendimento/paciente da instituição de origem.

Fontes: importações novas convertem famílias fora do perfil antes de medir o DOCX. Para um documento existente, Corrigir estrutura de texto ajusta apenas o layout aberto. Confira as posições e a impressão após corrigir fontes antigas.
